# Profile: Dionysios Kyriakongonas

## Summary
Dionysios Kyriakongonas is a web developer in Athens, Greece. He builds working web software with Claude Code. All nine of his live client sites are connected to Claude as MCP servers through Novamira, so he changes, extends and debugs them by working with an AI agent directly inside WordPress, then reads and fixes the code it writes. On four of them he built the internal apps the client runs their work on: a members area for parents, admin panels for a club office, a shop and an events venue, and a class schedule that builds itself. Since 2023 he has delivered 20 websites and e-shops in Athens. Besides the nine client sites he also built Pame Theatro (pame.gowebgo.gr), a theatre guide that uses the Claude API to turn press releases into structured show data, with a person approving every entry, and moved his own studio site gowebgo.gr from WordPress to Next.js with GitHub Actions for deployment and rollback.
